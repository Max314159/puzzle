拼图小游戏

一个纯静态的拖拽拼图游戏：多关卡、每关不同原图、可配置切分数量与限时。没有构建步骤，也没有任何依赖，浏览器直接打开就能玩。



玩法

每关开局全屏展示黑白原图约 2 秒，屏幕中央从 3 开始倒计时。



倒计时结束后大图变为空格，打乱的小图出现在下方（宽屏/横屏时在右侧）。



两种放置方式：



拖拽：按住小图拖到目标格子松手。



点击：先点小图，边缘出现金色实线框，再点大图里的格子即可放入；再点一次小图取消选中。



拖到已有图块的格子上会与原来的块交换位置。



全部放对后全屏显示彩色原图，四周有流动金光，3 秒后弹出下一关提示。



每局限时 5 分钟（可配）。超时会提示重开本关；右上角「重新开始」随时可重开当前关，含预览和倒计时。



本地运行

电脑

直接双击 index.html 即可，或者用任意静态服务器打开。



手机（推荐：电脑当临时服务器，手机同 Wi-Fi 访问）

在项目目录启动一个静态服务器：



powershell

cd C:\\Users\\xiangma\\projects\\jigsaw-puzzle

python -m http.server 8080

http.server 是 Python 标准库自带的模块，不是本项目里的文件，-m 表示运行这个已安装的模块，无需额外下载。它会把当前所在目录作为网站根目录发布。



如果 python 命令弹出 Microsoft Store 或提示找不到，改用 Windows 自带的启动器 py -m http.server 8080。两者都不可用

说明没装 Python, 可改用 Node:



powershell

npx --yes serve . -l 8080

首次运行时 Windows 防火墙会弹窗，勾选「专用网络」允许，否则手机连不上。



服务启动后终端会持续输出访问日志并保持运行，期间不要关闭窗口；需要停止时按 Ctrl + C。



查电脑的局域网 IP：



powershell

ipconfig | Select-String IPv4

手机浏览器打开 http://<上一步的IP>:8080/，例如 http://192.168.1.23:8080/。



手机和电脑需在同一个 Wi-Fi，且路由器没开 AP 隔离（部分访客网络会隔离设备，导致访问不通）。



手机（不开服务器）

把整个文件夹拷到手机，用浏览器打开里面的 index.html。所有资源都是相对路径、脚本是普通 <script>，因此 file:// 下可以正常运行。安卓 Chrome 可直接输入 file:///storage/emulated/0/Download/jigsaw-puzzle/index.html；iOS Safari 无法打开本地文件夹，需要借助能托管本地目录的 App。



在浏览器菜单里「添加到主屏幕」可以全屏打开，地址栏不再占用高度。



配置

所有可调项都在 config.js：



字段	说明

timeLimitMs	每局限时，单位毫秒。默认 5 \* 60 \* 1000

previewMs	开局黑白原图的展示时长

countdownFrom	开局倒计时的起始数字

nextLevelDelayMs	通关金光动画后，弹出下一关提示的等待时间

fallbackImageSrc	某一关图片加载失败时使用的兜底图

levels	关卡数组，顺序即通关顺序

每个关卡对象：



字段	说明

title	关卡名称，显示在页面顶部和通关提示里

cols	横向切分数量

rows	纵向切分数量

imageSrc	这一关的原图路径，每关可以不同

示例：把第三关换成自己的图并改成 6 × 4：



javascript

{

&#x20; title: "夜城灯火",

&#x20; cols: 6,

&#x20; rows: 4,

&#x20; imageSrc: "./assets/my-city.jpg",

}

增删关卡就是往 levels 里增删元素，不需要改其他代码。



换图

把图片放进 assets/，再在对应关卡写上 imageSrc 即可，jpg / png / svg / webp 都可以。



图片选择上的两点建议：横向长图（如 4:3、16:9）在电脑上观感更好；细节丰富、色块区分明显的图更容易辨认图块，纯色大面积的图会显著增加难度。



图片的实际宽高比会决定拼图板的比例和每个小块的形状，无需手动设置。

布局与屏幕适配

固定为「拼图板在左、待拼图块在右」的布局。图块区是竖排单列，放不下时在该列内部纵向滚动，不会把页面顶长。这种布局对竖图（height > width）尤其合适。



拼图板宽度同时受容器宽度、最大宽度、以及「可用高度 × 原图宽高比」三重约束，可用高度由脚本按真实布局测量，因此大图始终完整落在屏幕内且不变形。



右侧图块区与拼图板等高，高度由脚本写入的 --board-h 决定，并监听窗口缩放、屏幕旋转与可视区域变化自动重算。



小图的宽高比跟随当前关卡的单元格形状，与大图格子保持一致；从右侧拖出时的跟手残影按目标格子尺寸显示。



触屏上在图块区纵向滑动是滚动列表，横向拖动才是把图块拖向大图；也可以完全用「点图块 → 点格子」的点击方式，不需要拖拽。



字号与间距使用 clamp()，高度使用 dvh，并预留了刘海屏安全区内边距，双指缩放可用。



可调的两个布局变量在 styles.css 的 :root 里：



变量	说明

\--tray-col-w	右侧图块列的宽度，默认 clamp(76px, 16vw, 150px)，宽屏与超小屏另有覆盖值

\--tray-columns	图块排几列，默认 1（竖排单列）。改成 2 或 3 就是多列排布

浏览器要求

使用了 aspect-ratio、dvh、:has()、ResizeObserver 等特性，建议 Chrome / Edge 110+、Safari 16+、Firefox 121+。开启了系统级「减少动效」时，金光与计时器的动画会自动关闭。
